# RIG REPAIR — PC修理工房 / MICRO DETAIL EDITION v1.1

高性能スマートフォン向けの、ブラウザで遊ぶ3D PC修理・工房経営シミュレーターです。秋葉原の小さな修理工房のオーナーとして、症状から原因を調べ、修理し、納品して工房を育てます。自由移動型ではなく、精密なPCを中心に据えたワークベンチ型のゲームです。

## v1.1の詳細化アップデート

### PC内部の微細表現
- 既存モデルに **6,066個の微細立体ディテール** を追加。基板ビア、はんだ、抵抗、端子、CPUソケット接点、メモリ接点、ARGB発光素子などを実ジオメトリで表現。
- 45度に曲がるバス配線、部品番号・極性記号の基板印刷、CMOS電池、ICの個別リード、BIOSチップ、クロック発振器。
- 金属の加工痕・小傷・微細な凹凸、編み込みケーブルのバンプマップ。
- 分解図で見えるGPU基板、GPUダイ、VRAM、放熱パッド、金端子。
- 4096pxシャドウマップ、SSAO、ブルーム、環境反射。
- 実GPUでは端末のネイティブ解像度を使用。SwiftShader等のCPU描画環境だけは、合成表示の安定性のため描画バッファを1倍にします。部品数・照明・影の設定は変えません。

### 精密観察ツール
- **接写**：選択した部品へ寄り、左右ボタンで6部品を切替。パーツ詳細画面からも移動できます。
- **分解図**：主要部品を立体的に分離し、位置関係を線で表示。観察用なので在庫・時間・修理状態は変わりません。
- **温度**：診断結果をもとにした模式的な状態オーバーレイ。未診断部品はグレーです。実際の熱流体解析やセンサー読取ではありません。
- **検査灯**：視点位置から追加照明を当てます。
- **RGB**：ICE / SPECTRUM / WHITE / OFFを切替。

### 6種類の専門整備
通常の修理部品を選んだあと、ネジ外し画面の **「専門整備で、もっと深く。」** から選択できます。従来の精度ゲージ・自動作業も利用できます。

| 部品 | 専門整備内容 |
| --- | --- |
| CPU | 指でなぞってグリスを均一に塗布。塗布率とはみ出しから採点 |
| RAM | A2/B2への2枚装着と両側ラッチ固定 |
| GPU | 6枚のVRAMに指定厚のサーマルパッドを配置 |
| SSD | EFI / SYSTEM / DATA / RECOVERYを正しい移行先へ対応 |
| PSU | GND基準を確保して12V→5V→3.3Vを測定するゲーム内テスター |
| FAN | 4温度点のスライダーで静音・冷却カーブを設定 |

専門整備も通常修理と同じ部品・所要時間を消費します。完了までは消費せず、取消可能。精度85%以上で+¥800、60%以上で+¥400を納品時に加算します。現実の修理作業の指示ではありません。

### 整備カルテ
- 部品ごとの3項目の診断読取値を追加。未診断時は未測定表示、修理後は正常値へ変化。
- 診断、パネル着脱、交換方法、精度、清掃、テスト、納品をゲーム時刻付きで記録。
- 作業中の記録は最大100件、納品済みカルテは直近25台を保存。
- 依頼パネルの「整備カルテ・過去の修理記録」から閲覧。
- 旧セーブを維持。必要な拡張フィールドは作業時に追加されます。

## 実装済み機能

### 3D PC / グラフィック
- Three.jsによる、実際に回転・拡大・選択できる3D PC。
- 基板、回路パターン、表面実装部品、コンデンサ、ネジ、端子、DIMMスロット、RGBメモリ。
- 水冷CPUクーラー、熱交換器のフィン、配管、GPUと放熱フィン、NVMe SSD、電源、ケーブルコーム付き個別配線。
- 3連ARGBフロントファン、上部ファン、GPU冷却ファン、金属メッシュ、透明サイドパネル。
- ケースパネルの着脱アニメーション、清掃によるホコリの除去、CPU修理に連動する温度表示。
- PC電源ON時にファンが回転。電源OFF時も、検査台の低電圧照明としてRGBを表示。

### 修理ゲーム
- 顧客の症状・納期・報酬を持つ7種類の依頼テンプレート。

- 個別診断 / 全体診断。
- パネルを外す → 診断済み故障部品の修理 → 清掃 → パネル復旧 → 起動テスト → 納品。
- 4か所を順番にタップする固定ネジの取り外しミニゲーム。
- 取り付け精度 / グリス塗布量のタイミングチャレンジ。
- 精度85%以上で+¥800、60%以上で+¥400の納品ボーナス。
- 自動作業も選択可能（精密作業ボーナスなし）。
- 起動、メモリ、ストレージ、GPU、CPU冷却の5段階テスト表示。
- 未診断・正常部品・在庫不足・開いたケース・未修理PCの納品に対する操作制限。

## 初めてのプレイ

1. `index.html` をプレビューで開きます。
2. 「診断」→「全体診断」。CPUの冷却不良が見つかります。
3. 「パネルを外す」→「修理・交換」。支給された標準グリスを選びます。
4. 1→2→3→4の順にネジをタップ。ゲージを中央で止めて修理します。自動作業でも構いません。
5. 「クリーニング」→「パネルを戻す」→「起動テスト」。
6. テスト合格後に納品し、報酬を受け取ります。
7. 次の依頼を受注。必要な部品を仕入れ、利益を残します。
8. 「営業を終える」で固定費を払い、新しい一日へ進みます。

最初の修理は追加の仕入れなしで完了できます。スターター部品の参考原価は納品画面に表示しますが、受取時に再度差し引かれることはありません。

## データモデルと保存

バックエンド、Table API、D1、R2は使用していません。

- localStorageキー：`rig-repair-save-v1`
- `version`, `day`, `minute`, `cash`, `rep`, `completed`, `revenue`, `expenses`, `debt`
- `active`：症状・故障部位・診断済み部位・修理済み部位・納期・パネル・通電・清掃・テスト・各種ボーナス
- `inventory`, `premiumStock`：品目キーと個数
- `upgrades`：診断装置、仕入契約、修理工具の導入状況
- `accepted`：当日の受注済み依頼キー
- `ledger`：最新60件の入出金履歴
- `dailyTotals`：当日の累積入金、支出、修理売上
- `days`：直近14日の日次レポート（グラフは最大7日）
- `settings`：サウンド・パーツラベル
- `active.serviceLog`：作業時刻・操作・部品・作業内容の記録
- `serviceArchives`：納品したPCの情報と作業記録（直近25台）
- 接写・分解・照明などの観察モードは一時状態で、セーブには保存しません

保存はブラウザ・端末ごとです。クラウド同期はありません。ブラウザのサイトデータ削除やプライベートセッション終了で消失する場合があります。保存領域が利用できない場合は警告します。

## テスト

`tests.html`に、経済・修理・旧セーブ互換性・整備記録・専門整備UI・3D観察操作を含むテストを実装。ブラウザで **59 passed / 0 failed** を確認しています。CPU手動塗布については未塗布完了の防止・取消と採点関数を自動検証していますが、実機の指操作での全面塗布は未検証です。

検証対象：
- 修理から納品までの一連の操作
- 6種類の故障、複合故障、正常部品の交換防止
- 在庫消費、価格、プレミアムと精度ボーナス
- 二重納品防止、作業時間・資金不足時の非破壊的な拒否
- 家賃、利息、融資上限、返済、納期減額
- 設備投資、評判と報酬、依頼解放
- 日次集計の履歴件数上限に対する正しさ
- ネジ順序、ゲージ得点、ショップ、受注、営業終了の実UI
- 状態のJSON往復とデモセッションの分離

実ページをスマホ390px・デスクトップ1280pxで描画確認済み。ソフトウェアWebGLを使う検証ブラウザからGPU警告は出ますが、アプリのJavaScript例外は検出されていません。実機での長時間負荷・端末別フレームレート計測は未実施です。

## 未実装 / 制約

- 工房内の一人称自由移動、街の探索、人物の3Dモデル・会話アニメーション。
- 顧客PCごとの別ケース形状。現状は共通の精密モデルで依頼名と故障状態を切り替えます。
- 実機相当の回路シミュレーション、現実の修理手順の完全再現。
- 部品を手でドラッグして着脱する自由組立、ケーブルを端子へ手動接続する操作。
- ブランドやソケットごとの部品互換性。現状のショップ部品は全依頼に適合します。
- オンラインランキング、クラウドセーブ、複数端末同期、マルチプレイ。
- PWA・完全オフライン配信。
- 不正操作対策。ローカルの一人用ゲームなので、クライアント内の状態を秘密として保護する設計ではありません。
